# 🧮 CodeAlpha Calculator

A modern, glassmorphism-style calculator built with vanilla HTML, CSS, and JavaScript — featuring a live calculation history, full keyboard support, and a smooth dark/light theme toggle.

> Built as part of the **CodeAlpha Web Development Internship**.

---

## ✨ Features

- **Standard arithmetic** — addition, subtraction, multiplication, division, and percentage
- **Calculation history** — every equation and result is logged and shown in a scrollable list, with a one-click "Clear" option
- **Full keyboard support** — type numbers and operators directly, `Enter` to calculate, `Backspace` to delete, `Escape` to clear
- **Dark / Light mode** — toggle instantly with the moon/sun button, no page reload
- **Error handling** — invalid expressions and math errors (e.g. divide by zero) are caught and shown clearly instead of crashing
- **Clean, responsive UI** — Poppins font, soft gradients, and a card-based layout that works on any screen size

## 🚀 Getting Started

No build tools or dependencies required — it's pure HTML/CSS/JS.

1. **Clone the repository**
   ```bash
   git clone https://github.com/MuhammadUsman/CodeAlpha_Calculator.git
   ```
2. **Open it in your browser**
   ```bash
   cd CodeAlpha_Calculator
   open index.html   # or just double-click the file
   ```

That's it — no installation, no server needed.
